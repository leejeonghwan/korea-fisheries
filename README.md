# 한국 수산업 56년

1970~2025년 어업생산동향조사로 본 한국 수산업의 구조 변화. 품종·지역별로 직접 돌려볼 수 있는 탐색기입니다.

**보기 →** https://leejeonghwan.github.io/korea-fisheries/

## 무엇을 보여주나

56년 동안 전체 생산량은 4.2배 늘어 2025년 393만 톤으로 사상 최대입니다. 그런데 **우리 바다에서 잡는 양은 줄었습니다.** 연근해어업은 1986년 172만 6천 톤이 정점이었고 2025년은 97만 8천 톤, 정점의 57%입니다. 늘어난 것은 양식입니다. 12만 톤에서 253만 톤으로, 이제 전체의 64%입니다.

품종을 들여다보면 더 선명합니다. 명태는 2008년부터 우리 바다에서 사실상 0입니다(2024년 23kg). 꽁치는 정점의 0.8%, 도루묵은 2.4%입니다. 반대로 고등어·삼치·방어는 늘었습니다. 바지락은 전국 생산량이 1989년 8만 3843톤에서 2025년 2만 1511톤으로 줄었는데, 전북은 열에 아홉이 사라진 반면 경남은 2018년, 인천은 2023년에 정점을 찍었습니다.

## 자료

국가데이터처 「어업생산동향조사」(KOSIS)

| 표 | 내용 |
|---|---|
| `DT_1EW0001` | 어업생산동향 총괄표 — 어업별·지역별 |
| `DT_1EW0004` | 어업별 품종별 통계 — 품종 427종 |

2025년은 확정치이며 KOSIS 최종 수정 2026년 4월 29일 기준입니다.

해양수산부가 2026년 2월 25일 발표한 2025년 생산금액은 10조 2336억 원이고, 이 페이지의 10조 2366억 원은 그 뒤 수정된 KOSIS 값입니다. 생산량 393만 톤, 전년비 8.7% 증가, 연근해 16.3% 증가는 발표와 같습니다.

## 다룰 때 주의할 것

**품종 코드는 어업별 트리입니다.** 코드 첫 자리가 1이면 연근해, 2는 해면양식, 3은 원양, 4는 내수면입니다. 그래서 이름이 같아도 코드가 다릅니다 — 명태는 연근해(`110072`)와 원양(`310290`)이 따로 있고, 이런 품종이 108개입니다. **각 코드의 '계'는 그 코드 자신의 합계일 뿐 어업을 가로지른 합이 아닙니다.** 이름으로만 묶으면 숫자가 틀립니다. 실제로 그렇게 묶으면 명태 2025년이 연근해 0톤인데 원양 2만 9200톤에 덮여 2만 9200톤으로 보입니다.

`03_품종별_어업별.csv`의 `구분` 열이 `묶음`인 행은 분류 소계(어류·갑각류 등)입니다. 개별 품종만 쓰려면 `품종`인 행만 거르세요.

**생산금액은 명목입니다.** 물가 영향이 들어 있어 긴 시계열을 금액으로 비교할 때는 감안해야 합니다.

## 다시 만들기

```bash
export KOSIS_API_KEY="..."      # https://kosis.kr/openapi 에서 발급
python3 fetch.py                 # 총괄표
python3 -c "import fetch; fetch.species(); fetch.regional()"
python3 tidy.py                  # data/ → csv/
python3 -c "import tidy; tidy.regional()"
python3 bundle.py                # csv/ → data.js
```

받아둔 원자료는 `data/`에 남고 다시 받지 않습니다. 새로 받으려면 그 폴더를 비우면 됩니다.
